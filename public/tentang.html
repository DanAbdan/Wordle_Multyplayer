Tentang game ini

Tebak Kata KBBI adalah game tebak kata 5 huruf bareng teman, dibuat sebagai proyek belajar dan hiburan. Gratis, tanpa iklan, dan bukan produk komersial.

Game ini tidak resmi dan tidak berafiliasi dengan Badan Bahasa, Kemendikdasmen, atau pengelola KBBI. Daftar kata disusun dari kosakata KBBI dan bisa saja ada kata yang kurang atau keliru. Bukan rujukan kebahasaan resmi.

Karena berjalan di layanan hosting gratis, game bisa sesekali lambat, tidur saat sepi, atau tidak tersedia tanpa pemberitahuan. Room yang sedang berjalan bisa hilang kalau server restart.

Kamu boleh main sebagai tamu (hanya nickname, tanpa akun). Data berikut hanya ada kalau kamu membuat akun:

Isi room (tebakan, skor ronde, stiker yang dikirim) hanya disimpan sementara di memori server selama room aktif dan hilang saat room bubar atau server restart. Chat bebas tidak ada.

Yang tidak kami lakukan

  • Tidak meminta email, nomor telepon, atau data pribadi lain.
  • Tidak memasang analitik, iklan, atau pelacak pihak ketiga.
  • Tidak menjual atau membagikan datamu.

Pihak ketiga yang dipakai

  • Render menjalankan server game.
  • Upstash menyimpan data akun dan peringkat.

Keduanya memproses data sebagai penyedia infrastruktur, dan alamat IP kamu bisa tercatat di log teknis mereka seperti pada layanan web pada umumnya.

Tips keamanan

  • Pakai password yang tidak sama dengan akun lain (email, medsos, bank).
  • Pilih foto profil yang aman ditampilkan ke teman-temanmu. Jangan unggah foto orang lain tanpa izin.
  • Nama akun dan foto terlihat pemain lain, jadi jangan memakai nama lengkap kalau tidak mau.

Hak kamu: lihat, ubah, hapus

  • Kamu bisa mengganti password dan menghapus foto sendiri lewat tombol 👤 di game.
  • Untuk menghapus akun beserta semua datanya (nama, foto, poin, peringkat), atau reset password yang lupa, hubungi admin di bawah. Penghapusan dilakukan admin dan bersifat permanen.
  • Data tiap pemain hanya sebatas yang tertulis di tabel di atas.

Aturan main

  • Jangan memakai nickname, nama akun, atau foto yang menyinggung, berisi SARA, pornografi, atau menyamar sebagai orang lain.
  • Jangan mencoba mengganggu server atau akun pemain lain.
  • Admin berhak menghapus akun, foto, atau stiker yang melanggar.

Anak di bawah umur

Game ini ditujukan untuk umum dan tidak meminta data pribadi. Anak di bawah umur sebaiknya bermain dengan sepengetahuan orang tua atau wali.
