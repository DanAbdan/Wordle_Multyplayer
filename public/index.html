      Cara main

      • Tebak kata KBBI 5 huruf dalam 6 kesempatan. Semua pemain di room menebak kata yang sama dan serentak.
      • A Hijau + tanda ✓: huruf benar dan posisinya tepat.
      • B Kuning + tanda ●: huruf ada di kata, tapi posisinya salah.
      • C Abu-abu gelap: huruf tidak ada di kata.
      • Poin: 100 untuk menjawab benar + sampai 400 bonus kecepatan. Salah semua = 0 poin.
      • Mode Skill: tiap 3 ronde kamu dapat 1 skill baru (sekali pakai): 🔍 Intip, 🚫 Coret, ❄️ Bekukan, 🛡️ Perisai, ⚡ Skor Ganda.
      • Tombol 🙂 di pojok kanan bawah untuk kirim stiker ke teman satu room.
      • Akun (👤): daftar atau masuk supaya nama dan foto profilmu tetap sama setiap main. Tamu tetap bisa main, tapi tidak masuk peringkat.
      • Peringkat (🏆): dihitung per minggu (Senin-Minggu, WIB) dari semua game: jumlah jawaban benar dan streak benar terbanyak.
      • Host bisa menekan Batalkan game kalau salah setting. Game yang dibatalkan tidak dihitung ke peringkat.
      • Pemain lain hanya terlihat warnanya saja, hurufnya rahasia.
